## Summary

This PR fixes two critical issues:
1. **API endpoint not yet implemented** error for `/api/backtest/*` routes
2. **Session expired** error after login in production

## Changes Reviewed

### 1. Worker API Endpoints (`worker/src/index.ts`)

**Added Routes:**
- ✅ `GET /api/backtest/realistic` - Realistic backtest endpoint
- ✅ `GET /api/backtest/edge` - Edge case backtest endpoint

**Session Tracking Fix:**
- ✅ Fixed `/api/auth/me` to update `last_accessed` for JWT tokens
- ✅ Unified logic for both JWT and database sessions
- ✅ Proper session tracking for all token types

**Impact:**
- Resolves "API endpoint not yet implemented" error
- Enables backtest endpoints in production
- Improves session persistence tracking

### 2. Frontend Session Handling (`aurum_harmony/frontend/flutter_app/lib/services/auth_service.dart`)

**Session Expiration Fixes:**
- ✅ Network errors no longer count as validation failures
- ✅ `_lastValidationTime` only updated on success (not failures)
- ✅ Better distinction between network errors and auth errors
- ✅ Faster retry on temporary failures
- ✅ Grace period (15s) and validation interval (2min) maintained

**Impact:**
- Resolves false "Session Expired" messages after login
- Better handling of network timeouts
- Improved user experience in production
